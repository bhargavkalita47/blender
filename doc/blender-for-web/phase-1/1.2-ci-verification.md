## Native CMake configuration attempt

Workflow: https://github.com/bhargavkalita47/blender/actions/runs/42370125806

The workflow performed an actual CMake configure **attempt**, using Clang 18, Ninja, Blender's `blender_lite.cmake`, headless flags, a source checkout and selected Ubuntu native development packages.

**Result:** configure did not complete. The CI runner does not currently have the required `OpenColorIO` 2.3.0 CMake package configuration (diagnostic from `build_files/cmake/platform/platform_unix.cmake:124`, invoked from line 458). The system package installed with apt did not supply a usable required package version/configuration.

Earlier probes established that a sparse checkout may only contain a Git LFS pointer for `startup.blend`, and that basic image headers and utilities (JPEG, `iconvert`) must also be provisioned. These were handled in later CI attempts. They are **environment/toolchain issues**, not a proven defect in BKE or BMesh.

The workflow uploads `configure.log` and `probe-status.txt` as `blender-web-p1-2-native-configure-probe`. The workflow can finish green because its purpose is recording probe evidence; that **must not** be mistaken for a passing CMake configure (the recorded `configured=no` is authoritative).
