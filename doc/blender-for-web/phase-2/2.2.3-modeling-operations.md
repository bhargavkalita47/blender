## First verified modeling slice

1. **Plane primitive**: creates four Blender `BMVert` elements and one `BMFace` via original Blender BMesh constructors, with one valid `BMLoop` radial ring on each of the four boundary edges. This is an open mesh, not a cube.
2. **Whole-mesh translation**: exposes `web_mesh_translate(handle, dx, dy, dz)` through the same generation-checked opaque native BMesh handle system. Moves `BMVert.co` after checking all supplied components are finite and the operation would not overflow the float storage. This is a *thin coordinate editing adapter*, **not yet a port of Blender's own `BMO translate` operator**.
3. **Topology validation**: upgrades the former closed-cube-only validator so it checks both one-face boundary edges and two-face manifold edges. Rejects invalid adjacency/radial links and unsupported non-manifold cycles.
4. **Multi-object independence**: test creates a cube and plane concurrently, transforms the plane, and checks the cube has not changed. Invalid handles, stale handles, nonfinite translation parameters, and an attempted cube-only extrusion on the plane are rejected.

The initial fixture covers exactly one 2×2 plane at Z=0 followed by a (0.5, -1.0, 2.0) translation. It retains cube primitive and original Blender discrete-face extrusion tests.

## Pinned Blender reference parity

CI retrieves the official Blender 5.4 Alpha Linux executable matching commit `67e5a5f874cf`. The original `bmesh.ops.create_grid(x_segments=1, y_segments=1, size=1.0)` and `bmesh.ops.translate(verts=..., vec=...)` produce the independent reference.

A separate Python process accesses the newly compiled original-Blender C++ native core via `ctypes` and extracts quad vertices and triangles from the BMesh API. A strict parity comparison checks canonical coordinates, edges, winding, face normals/areas and exact triangle/loop counts.

The workflow also builds the independent native shared library, executes the pre-existing 1,000-cycle cube/extrusion regression, runs 1,000 new plane create/translate/destroy cycles, verifies no net tracked Blender allocation remains, confirms simultaneous mesh independence, and rechecks for accidental desktop renderer/window-manager dependencies.

The source-pinned parity record includes `reference_build_hash: 67e5a5f874cf`, `status: pass`, `vertex_edge_face_winding_normal_area_parity: true`, `simultaneous_mesh_isolation: true`, and `native_memory_baseline_equal_final: true`.
